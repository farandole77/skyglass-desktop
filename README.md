# 스카이글라스 데스크 (PC · 서브모니터용)

하늘·날씨 배경 위에 **할 일 · 일정(회의) · 알람**을 함께 보는 데스크 대시보드. 설치 프로그램·계정·서버가 필요 없는 정적 웹페이지이고,
데이터는 **이 브라우저에만** 저장된다(백업 기능 있음). 날씨는 Open-Meteo 무료 API(키 없음, 개인·비상업 용도).

## 화면 구성
- 왼쪽: 날짜 · 큰 시계 · 날씨 · **다음 일정 / 다음 알람**(남은 시간 표시)
- 오른쪽 패널: **할 일 / 일정 / 알람** 탭 (`–` 버튼이나 `H` 키로 접기, 접으면 작은 알약 모양으로 요약만 표시)
- 톱니바퀴: 스킨 5종(미니멀·하늘·지평선·월광·천문도), 시계 글꼴·크기·위치·색, **알림·소리 설정**
- 가로로 아주 긴 바 모니터(1920×480 등)에서는 시계 | 날씨 | 패널 3단 배치로 자동 전환

## 사용법
**할 일** — 아래 칸에 적고 Enter / 동그라미 = 완료 / 글자 더블클릭 = 수정 / 끌어서 순서 변경 / × = 삭제
**일정** — `＋ 일정 추가`: 제목·날짜·시간·알림(정시~1시간 전)·반복(매일/평일/매주)·회의 링크(Teams·Zoom·Meet). 목록에서 `참여` 버튼으로 링크를 연다. 항목을 누르면 수정·삭제.
**알람** — `＋ 알람 추가`: 시간·이름·반복 요일(고르지 않으면 한 번만). 스위치로 켜고 끈다. 울리면 큰 화면이 뜨고 `N분 뒤 다시`(스누즈) / `끄기`.
**일정 알림** — 설정한 시각에 화면 위에 알림창이 뜨고 짧은 알림음이 난다.

단축키: `1` `2` `3` 탭 이동 · `N` 또는 `/` 새로 추가 · `H` 패널 접기 · `F` 전체화면(빈 곳 더블클릭도 가능)

## 알람이 울리는 조건 (꼭 읽기)
- **이 화면(브라우저 창)이 열려 있고 PC가 켜져 있어야 한다.** PC가 절전 상태이면 울리지 않는다. (절전에서 깬 직후 15분 이내에 놓친 알람은 울린다)
- 소리는 브라우저 정책상 **화면을 한 번 클릭한 뒤부터** 난다. 클릭 전이면 패널 아래에 '🔇 소리 알림: 화면을 한 번 클릭해 주세요'가 뜬다.
- 데스크톱 알림(윈도우 알림 센터)은 https 주소에서 허용했을 때만 동작한다. 허용하지 않아도 화면 안 알림창과 소리는 동작한다.

## 실행 방법
### A. 그냥 폴더째 쓰기 (호스팅 없이)
1. 압축을 풀어 자리를 정해 둔다 (폴더를 옮기면 데이터가 초기화되니 고정할 것)
2. `Start-Desk.bat` 더블클릭 → 주소창 없는 Edge 전체화면 창. 서브모니터로 보내려면 bat를 메모장으로 열어 `POS=` 좌표 수정
3. 부팅 시 자동 실행: `Win + R` → `shell:startup` → 열린 폴더에 bat의 **바로 가기** 넣기
※ 이 방식(file://)에서는 브라우저 제한 때문에 **데스크톱 알림·위치·화면 꺼짐 방지·오프라인 저장이 안 된다.** 위치는 아산 기준으로 고정된다.

### B. 웹에 올려서 앱으로 설치 (추천)
1. 새 GitHub 저장소에 이 폴더 **안의 내용물**을 최상위에 올리기 (`index.html`이 저장소 맨 위에 보여야 함)
2. Vercel → Add New → Project → Import → Framework Preset **Other** → Deploy
3. Edge에서 나온 주소를 열고 주소창 오른쪽 **앱 사용 가능 → 설치**
4. 자동 시작: `edge://apps` → 스카이글라스 데스크 ⋯ → **장치 로그인 시 자동 시작**
5. 서브모니터에 고정하려면 `Start-Desk.bat`의 `URL=`에 배포 주소를 넣고 `POS=` 좌표를 맞춘 뒤 이 bat를 시작프로그램에 넣는다.
이 방식은 데스크톱 알림·위치·화면 꺼짐 방지가 모두 동작하고, 인터넷이 끊겨도 화면이 뜬다.

## 데이터와 백업
- 할 일·일정·알람은 브라우저 저장소에만 있다. 브라우저 데이터를 지우거나 다른 PC/브라우저에서 열면 비어 있다.
- 패널 아래 **백업**으로 .json 파일을 저장하고 **복원**으로 불러온다. (다른 PC로 옮길 때도 이 방법)
- 가끔 백업해 두자.

## 참고
- 지도 실루엣(하늘·지평선·월광 스킨)은 인터넷과 WebGL이 필요하다. 안 되면 장식용 격자무늬로 대체된다.
- 주소 옵션: `?skin=horizon|moon|sky|dots|minimal`, `?weather=rain|snow|storm|fog|cloud|clear`, `?hour=21`, `?h12=1`
- 우측 상단 길게 누르기: 진단 화면(위치·날씨·오류)
