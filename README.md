# 스카이글라스 데스크 (PC · 서브모니터용)

하늘·날씨 배경 위에 **할 일 · 일정(회의) · 알람**을 함께 보는 데스크 대시보드. 설치 프로그램·계정·서버가 필요 없는 정적 웹페이지이고,
데이터는 **이 브라우저에만** 저장된다(백업 기능 있음). 날씨는 Open-Meteo 무료 API(키 없음, 개인·비상업 용도).

## 화면 구성
- 왼쪽: 날짜 · 큰 시계 · 날씨 · **다음 일정 / 다음 알람**(남은 시간 표시)
- 오른쪽 패널: **할 일 / 일정 / 알람** 탭 (`–` 버튼이나 `H` 키로 접기, 접으면 작은 알약 모양으로 요약만 표시)
- 톱니바퀴: 스킨 5종(미니멀·하늘·지평선·월광·천문도), 시계 글꼴·크기·위치·색, **알림·소리 설정**
- 가로로 아주 긴 바 모니터(1920×480 등)에서는 시계 | 날씨 | 패널 3단 배치로 자동 전환

## 사용법
**할 일** — 아래 칸에 적고 Enter / 동그라미 = 완료 / 글자 더블클릭 = 수정 / 끌어서 순서 변경 / × = 삭제
**업무 시간 기록 (할 일 탭)** — 회사 업무 체크리스트에 시작·종료 시각과 소요시간을 적어야 할 때 쓴다.
- 항목 오른쪽 `▶ 시작` → 시각이 기록되고 실시간 타이머가 돈다(시계 아래에도 `진행 중 · 업무명 · 00:42:10` 표시).
- `‖ 일시정지` → 점심시간·휴식·퇴근 때. 타이머가 멈추고 업무는 목록에 **남는다**(노란색 '일시정지' 상태). 그 구간의 시간만 기록된다.
- `▶ 이어서 시작` → 일시정지한 업무를 다시 시작. **다음날에도 목록 위쪽에 그대로 있어서** 한 번만 누르면 된다. (어제 17:50까지 · 누적 3시간 50분)
- `■ 완료` (또는 진행 중 항목의 동그라미 체크) → 업무 완료. 완료를 취소하면 기록은 그대로 두고 일시정지 상태로 돌아간다.
- `진행 중 모두 일시정지`(할 일 탭 아래) → 점심·퇴근 때 한 번에.
- `Ctrl+Enter`로 입력하면 추가와 동시에 시작.
- 한 업무는 '작업 구간' 여러 개로 기록되고, 소요시간은 구간별 **화면에 보이는 분 단위 시각의 차이**를 더한다(예: 09:10→09:55 = 45분).
- **퇴근 알림**: 톱니바퀴 설정 → '퇴근 알림'에 시각을 넣으면, 그 시각에 진행 중인 업무가 있을 때 `모두 일시정지` 버튼이 있는 알림이 뜬다(끔 가능).
- **일시정지를 깜빡하고 퇴근한 경우**: 다음날 앱을 열면 '어제 업무가 아직 진행 중이에요' 창이 떠서 '작업을 멈춘 시각'(기본: 퇴근 알림 시각, 없으면 18:00)을 정해 일시정지/완료할 수 있다.
- 시간 줄(`09:10 → 12:00 · 3시간`)을 누르면 구간별 시작·종료 시각을 직접 고치거나 구간을 추가·삭제할 수 있다.
- `업무 기록`(할 일 탭 아래) → **날짜별** 표(업무 / 시작 / 종료 / 소요, 하루 합계). 어제 시작해 오늘 이어한 업무는 각 날짜에 그날 한 시간만 나온다.
  - 기본은 휴식을 뺀 순수 작업시간. `휴식 시간 포함`을 켜면 첫 시작~마지막 종료 전체를 소요시간으로 표시.
  - `복사`는 엑셀에 붙여넣을 수 있는 표, `CSV 저장`은 파일로 저장.
- `완료 항목 지우기`를 눌러도 시간 기록이 있는 업무는 목록에서만 사라지고 `업무 기록`에 **90일간 보관**된다. 백업 파일에도 포함된다.
- 예전 버전에서 기록한 시작/종료는 자동으로 새 형식으로 옮겨진다.

**일정** — `＋ 일정 추가`: 제목·날짜·시간·알림(정시~1시간 전)·반복(매일/평일/매주)·회의 링크(Teams·Zoom·Meet). 목록에서 `참여` 버튼으로 링크를 연다. 항목을 누르면 수정·삭제.
**알람** — `＋ 알람 추가`: 시간·이름·반복 요일(고르지 않으면 한 번만). 스위치로 켜고 끈다. 울리면 큰 화면이 뜨고 `N분 뒤 다시`(스누즈) / `끄기`.
**일정 알림** — 설정한 시각에 화면 위에 알림창이 뜨고 짧은 알림음이 난다.

단축키: `1` `2` `3` 탭 이동 · `N` 또는 `/` 새로 추가 · `H` 패널 접기 · `F` 전체화면(빈 곳 더블클릭도 가능)

## 알람이 울리는 조건 (꼭 읽기)
- **이 화면(브라우저 창)이 열려 있고 PC가 켜져 있어야 한다.** PC가 절전 상태이면 울리지 않는다. (절전에서 깬 직후 15분 이내에 놓친 알람은 울린다)
- 소리는 브라우저 정책상 **화면을 한 번 클릭한 뒤부터** 난다. 클릭 전이면 패널 아래에 '🔇 소리 알림: 화면을 한 번 클릭해 주세요'가 뜬다.
- 데스크톱 알림(윈도우 알림 센터)은 https 주소에서 허용했을 때만 동작한다. 허용하지 않아도 화면 안 알림창과 소리는 동작한다.

## 실행 방법
### A. 그냥 폴더째 쓰기 (호스팅 없이)
1. 압축을 풀어 자리를 정해 둔다 (폴더를 옮기면 데이터가 초기화되니 고정할 것)
2. `Start-Desk.bat` 더블클릭 → 주소창 없는 Edge 전체화면 창. 서브모니터로 보내려면 bat를 메모장으로 열어 `POS=` 좌표 수정
3. 부팅 시 자동 실행: `Win + R` → `shell:startup` → 열린 폴더에 bat의 **바로 가기** 넣기
※ 이 방식(file://)에서는 브라우저 제한 때문에 **데스크톱 알림·위치·화면 꺼짐 방지·오프라인 저장이 안 된다.** 위치는 아산 기준으로 고정된다.

### B. 웹에 올려서 앱으로 설치 (추천)
1. 새 GitHub 저장소에 이 폴더 **안의 내용물**을 최상위에 올리기 (`index.html`이 저장소 맨 위에 보여야 함)
2. Vercel → Add New → Project → Import → Framework Preset **Other** → Deploy
3. Edge에서 나온 주소를 열고 주소창 오른쪽 **앱 사용 가능 → 설치**
4. 자동 시작: `edge://apps` → 스카이글라스 데스크 ⋯ → **장치 로그인 시 자동 시작**
5. 서브모니터에 고정하려면 `Start-Desk.bat`의 `URL=`에 배포 주소를 넣고 `POS=` 좌표를 맞춘 뒤 이 bat를 시작프로그램에 넣는다.
이 방식은 데스크톱 알림·위치·화면 꺼짐 방지가 모두 동작하고, 인터넷이 끊겨도 화면이 뜬다.

## 상단에 작은 제목 줄(주소·앱 이름)이 보일 때
설치한 앱 창 위쪽의 얇은 줄은 Edge가 어느 사이트의 앱인지 보여주는 표시줄이다.
- 바로 숨기기: 화면에서 `F` 키(또는 빈 곳 더블클릭) → 전체화면이 되면서 줄이 사라진다. 다시 누르면 해제.
- 항상 숨기기: 이 버전의 `manifest.webmanifest`(앱이 전체화면으로 열리도록 설정됨)를 저장소에 덮어써 배포한 뒤,
  `edge://apps`에서 기존 앱을 **제거하고 다시 설치**한다. (이미 설치된 앱은 설정이 바뀌지 않는 경우가 있다)

## 휴대폰·태블릿에서 쓰기 (세로 화면 자동 대응)
같은 주소를 휴대폰 브라우저로 열면 화면 모양을 알아서 맞춘다. 별도 설정은 필요 없다.
- **세로 화면**(휴대폰·태블릿): 위쪽에 날짜·시계·날씨·다음 일정, 아래쪽에 할 일/일정/알람 패널이 큰 터치 버튼으로 나뉜다. 패널 오른쪽 위 `–`를 누르면 접히고, 알약을 누르면 다시 펼쳐진다.
- **가로로 돌린 휴대폰**: 시계 | 날씨 | 패널 3단(바 모니터와 같은 배치)으로 바뀐다.
- 터치 화면에서는 입력칸 옆에 `＋`(추가)와 `▶`(추가하고 바로 시작) 버튼이 보이고, 항목마다 `✎`(수정)·`×`(삭제)가 항상 보인다.
- **홈 화면에 추가**: Android Chrome은 `⋮ → 홈 화면에 추가(앱 설치)`, iPhone Safari는 `공유 → 홈 화면에 추가`. 앱 아이콘으로 바로 열린다.
- 지평선·월광·천문도 스킨도 세로 화면용으로 따로 배치된다(달은 시계 오른쪽, 지평선은 패널 위쪽, 천문도 지도는 가로 띠 형태).

**휴대폰에서 꼭 알아둘 점**
- 알람·일정 알림은 **이 화면이 켜져 있을 때만** 울린다. 화면이 꺼지거나 다른 앱을 쓰는 동안, 또는 브라우저가 백그라운드에서 멈추면 울리지 않을 수 있다. 중요한 알람은 휴대폰 기본 알람 앱을 쓰고, 여기서는 업무 시간 기록과 일정 확인 용도로 쓰는 것을 권한다. 설정의 `화면 꺼짐 방지`를 켜 두면 화면이 켜져 있는 동안은 유지된다.
- 소리는 화면을 한 번 터치한 뒤부터 난다(브라우저 정책). iPhone은 홈 화면에 추가한 앱에서만 알림이 되고(iOS 16.4 이상), 무음 스위치가 켜져 있으면 소리가 나지 않을 수 있다.
- 할 일 **끌어서 순서 변경**은 휴대폰 터치에서는 동작하지 않는다(컴퓨터에서만). 순서는 컴퓨터에서 바꾸거나 새로 적어서 맞춘다.
- 휴대폰과 컴퓨터는 **데이터가 따로 저장**된다(각 브라우저에만 저장). 옮기려면 컴퓨터에서 `백업` → 휴대폰에서 `복원`(백업 파일을 휴대폰으로 보내서).

## 스킨 9종 (시안 4종 추가)
톱니바퀴 → 스킨에서 고른다. 기존 5종(미니멀·하늘·지평선·월광·천문도)에 시안으로 만든 4종이 더해졌다.
- **바다**: 시간대별로 변하는 실시간 바다. 새벽 노을·낮·석양·밤, 수면의 반짝임, 실제 월령의 달
- **사계절 풍경**: 안개 낀 산림 계곡. 봄(벚꽃)·여름(반딧불)·가을(단풍)·겨울(눈). **오늘 날짜 기준 자동**이고, 설정(사계절 풍경 선택 시 맨 아래)에서 계절을 고정할 수 있다
- **오로라 밤하늘**: 호수에 비치는 오로라. 낮에는 은은하게, 밤에는 선명하게
- **도트 네온 시티**: 저녁 골목을 도트로 그린 거리. 창문 불빛·네온 간판·전철. 시계는 도트 글자로 바뀐다
- 시각은 실제 일출·일몰에 맞춰 늘이고 줄여 쓰고(계절이 바뀌어도 해가 뜨는 순간이 '새벽 노을'), 날씨는 실제 날씨(비·눈·흐림·안개)를 반영한다
- 세로 화면(휴대폰)에서는 풍경이 아래 패널 위쪽에 보이도록 올라가고, 패널을 접으면 전체 풍경이 보인다
- **성능**: 바다·사계절·오로라는 GPU로 그린다. 컴퓨터가 느리면 렌더 해상도를 자동으로 낮추고(100%→25%), 30fps로 제한한다. WebGL을 못 쓰면 단순 그라데이션으로 대체된다. 현재 상태는 우측 상단 길게 누르기 → 진단 화면의 '셰이더 스킨:' 줄에서 확인(렌더 해상도 %, GPU 시간 ms)
- 노트북 배터리·발열이 신경 쓰이면 도트 네온 시티·미니멀처럼 가벼운 스킨을 쓰고, 충전기를 꽂아 두는 것을 권한다

## 데이터와 백업
- 할 일·일정·알람은 브라우저 저장소에만 있다. 브라우저 데이터를 지우거나 다른 PC/브라우저에서 열면 비어 있다.
- 패널 아래 **백업**으로 .json 파일을 저장하고 **복원**으로 불러온다. (다른 PC로 옮길 때도 이 방법)
- 가끔 백업해 두자.

## 참고
- 지도 실루엣(하늘·지평선·월광 스킨)은 인터넷과 WebGL이 필요하다. 안 되면 장식용 격자무늬로 대체된다.
- 주소 옵션: `?skin=horizon|moon|sky|dots|minimal`, `?weather=rain|snow|storm|fog|cloud|clear`, `?hour=21`, `?h12=1`
- 우측 상단 길게 누르기: 진단 화면(위치·날씨·오류)
